# Dues

> Know what's due.

Dues is a free, open-source, local-first progressive web app for tracking
subscriptions, autopay mandates, and other recurring payments.

The project is currently in Phase 1: product definition. No application code
has been written yet.

## Product principles

- Free to use and self-host
- No account required
- No advertising or behavioural analytics
- Data stays on the user's device by default
- No bank credentials or complete payment-card details
- Offline-capable and installable as a PWA
- A documented, portable data format

See [docs/product.md](docs/product.md), [docs/security.md](docs/security.md), and
[docs/mvp.md](docs/mvp.md) for the initial product specification.

Implementation work across the four development worktrees is coordinated in
[docs/phase-1-parallel-plan.md](docs/phase-1-parallel-plan.md).
